# Assembly-Language

记录一下自己一个学期学习汇编语言（主要是16位）的实验报告。

后面也有关于利用 Visual Studio 2017 编写汇编的一些资料，推荐《基于x86处理机：汇编语言》。

## 目录结构

```
Assembly-Language/
├── README.md                 # 本文件
├── 课件/                     # 理论课课件（汇编语言_00 ~ _17）
├── 实验/                     # 实验课 PPT（实验01 ~ 实验12）
│   └── 截图/                 # 实验过程截图（按实验编号归档）
├── 实验报告/                 # 实验报告01 ~ 12、翻转课堂互评表
├── 代码/
│   ├── 源码/                 # .asm 汇编源文件
│   └── 构建产物/             # MASM 编译生成的 .EXE / .OBJ
├── 论文/                     # 课程论文（含 PDF 版）
│   ├── 参考文献/             # 写作参考的三篇论文
│   └── 翻转课堂资料/         # 递归与阶乘相关的 PPT 及文档
├── 参考资料/                 # 王爽《汇编语言》第3版、Intel 汇编、VC++ 使用指南
└── 软件/                     # DOSBox、MASM、LINK、debug 及 Irvine 库等工具
```

## 环境

16 位汇编使用 `软件/AsmTools/` 中的 DOSBox + MASM + LINK + debug；
Visual Studio 2017 汇编环境见 `参考资料/VC++使用.pdf` 与 `软件/Irvine.zip`。
